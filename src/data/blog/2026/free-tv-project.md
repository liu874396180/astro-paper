## 1. TVBox / TVBox 系生态

### TVBoxOSC

- **项目名称**：TVBoxOSC
- **GitHub 地址**：[https://github.com/o0HalfLife0o/TVBoxOSC](https://github.com/o0HalfLife0o/TVBoxOSC)
- **在线地址**：无
- **描述**：
  TVBox 的开源实现版本之一，Android 端影视壳应用，通过配置接口（JSON）聚合各类影视资源站，本身不提供内容，依赖第三方源。

### TVBox

- **项目名称**：TVBox
- **GitHub 地址**：[https://github.com/liu874396180/TVBox](https://github.com/liu874396180/TVBox)
- **在线地址**：无
- **描述**：
  TVBox 系列项目之一，适合自定义影视源接口使用，常被用于电视盒子、Android TV 环境。

### LibreTV

- **项目名称**：LibreTV
- **GitHub 地址**：[https://github.com/liu874396180/LibreTV](https://github.com/liu874396180/LibreTV)
- **在线地址**：[https://librevv.pages.dev/](https://librevv.pages.dev/)
- **描述**：
  基于 Web 的开源影视聚合项目，主打「无需安装 App，浏览器即可播放」，支持部署到 Cloudflare Pages、Vercel 等平台。

### MoonTV

- **项目名称**：MoonTV
- **GitHub 地址**：[https://github.com/liu874396180/MoonTV](https://github.com/liu874396180/MoonTV)
- **在线地址**：无
- **描述**：
  TVBox 衍生影视项目之一，偏向影视聚合与自定义源玩法。

### OuonnkiTV

- **项目名称**：OuonnkiTV
- **GitHub 地址**：[https://github.com/liu874396180/OuonnkiTV](https://github.com/liu874396180/OuonnkiTV)
- **在线地址**：无
- **描述**：
  同作者系列的影视播放项目，定位与 TVBox / LibreTV 类似。

### dongguaTV

- **项目名称**：dongguaTV
- **GitHub 地址**：[https://github.com/Minerchu/dongguaTV](https://github.com/Minerchu/dongguaTV)
- **在线地址**：无
- **描述**：
  一个影视聚合类 Web 项目，支持在线播放，多用于私有部署或学习用途。

### TVAPP

- **项目名称**：TVAPP
- **GitHub 地址**：[https://github.com/youhunwl/TVAPP](https://github.com/youhunwl/TVAPP)
- **在线地址**：https://app.iyouhun.com/
- **描述**：
  Android 平台影视播放应用，壳 + 接口模式，依赖配置源获取内容。收集全网 Android TV电视盒子应用，涵盖影视、直播、K歌、工具、游戏等类型，整理优质APK资源，支持便捷下载与自动更新。提供安全验证、分类索引与兼容性标注，助力用户打造家庭影音娱乐中心！ ✅ TVBox/影视仓等影音壳接口配置源
